# ECFSW-SyntheticData
Synthetic data for Effective feature-sample co-clustering by adaptive feature-sample co-weighting(ECFSW)

This data is shared under [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/) terms.  
If you use this data, please cite `Effective feature-sample co-clustering by adaptive feature-sample co-weighting`

The data is organized by experiments:  
- **Experiment 1 `Rationality of feature and sample importance mining`**: `synthetic_data1.mat`  
- **Experiment 2 `Correlation analysis between feature and sample clusters`**: `synthetic_data2.mat`  
- **Experiment 3 `Clustering performance evaluation`**: `synthetic_data3_noise02.mat`, `synthetic_data3_noise03.mat`, `synthetic_data3_noise04.mat`
